# 📄 เว็บแอปใบเสนอราคา / ใบแจ้งหนี้

เว็บแอปออกใบเสนอราคา (Quotation) และใบแจ้งหนี้ (Invoice) ภาษาไทย
ออกแบบมาให้ **ใช้บนมือถือเป็นหลัก** หน้าตามินิมอล และ **กดดาวน์โหลด PDF ได้ทันที**

➡️ **เริ่มต้นใช้งาน: อ่าน [SETUP.md](SETUP.md)** (ติดตั้งครั้งเดียว ~10 นาที ฟรีทั้งหมด)

## ความสามารถ

- 📱 ใช้งานผ่านมือถือเป็นหลัก (เพิ่มลงหน้าจอโฮมได้เหมือนแอป)
- 🔐 ระบบสมาชิก — ข้อมูล sync ทุกเครื่อง ดูเอกสารย้อนหลังได้ (Supabase ฟรี)
- 🏢 รองรับหลายบริษัท/หลายชื่อผู้ขาย สลับได้ตอนออกเอกสาร
- 🧾 ใบเสนอราคา (ธีมส้ม) + ใบแจ้งหนี้ (ธีมน้ำเงิน) เลย์เอาต์ตามเอกสารตัวอย่าง
- 🔁 แปลงใบเสนอราคา → ใบแจ้งหนี้ ได้ในคลิกเดียว หรือสร้างใบแจ้งหนี้แยกอิสระ
- 🔢 รันเลขเอกสารอัตโนมัติ (`QT20260616xxxx`) แก้เองได้
- 💰 ส่วนลด (บาท/%) · VAT 7% เปิด-ปิดได้ · หัก ณ ที่จ่าย 1/2/3/5%
- 📇 สมุดลูกค้า + สมุดสินค้า เลือกเติมอัตโนมัติ ไม่ต้องพิมพ์ซ้ำ
- ✍️ อัปโหลดโลโก้ / ลายเซ็น / ตราประทับ แปะลง PDF อัตโนมัติ
- 🏦 ข้อมูลบัญชีธนาคารแสดงในใบแจ้งหนี้
- ⬇️ ดาวน์โหลด PDF ฟอนต์ไทย Sarabun คมชัด + 📤 แชร์ไฟล์เข้า LINE/อีเมลจากมือถือ
- 🏷️ สถานะเอกสาร: ร่าง / ส่งแล้ว / อนุมัติ / ชำระแล้ว / ยกเลิก + ค้นหาเอกสาร

## โครงสร้างโปรเจกต์

```
index.html            หน้าเดียว (SPA) ไม่ต้อง build
css/style.css         สไตล์ทั้งหมด (มินิมอล mobile-first)
js/config.js          ⚙️ ใส่ค่าเชื่อมต่อ Supabase ที่นี่
js/app.js             ตัวแอป: หน้าจอทั้งหมด + เชื่อมฐานข้อมูล
js/pdf.js             สร้าง PDF ด้วย pdfmake (เลย์เอาต์เอกสาร)
js/utils.js           คำนวณยอด / จัดรูปแบบ / ย่อรูป
js/fonts-data.js      ฟอนต์ Sarabun ฝังเป็น base64 (ใช้ทั้งหน้าเว็บและใน PDF)
fonts/OFL.txt         สัญญาอนุญาตฟอนต์ Sarabun
vendor/               ไลบรารี pdfmake + supabase-js (เก็บในโปรเจกต์ ไม่พึ่ง CDN)
supabase/schema.sql   สคริปต์สร้างตาราง + นโยบายความปลอดภัย (รันครั้งเดียว)
SETUP.md              คู่มือติดตั้งภาษาไทย
```
